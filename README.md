# Сайт оплаты (книга) + lava.business + письмо с доступом

Минимальный сайт без UI/UX-дизайна: номер заказа, телефон, email, название и цена товара, кнопка оплаты. После успешной оплаты отправляется письмо со ссылкой на вход в Telegram-канал с книгой.

## Что настроить в LAVA

- Создайте API key (он используется вашим сервером для вызова API LAVA) и укажите его в `LAVA_API_KEY`.
- Возьмите `offerId` (идентификатор оффера/цены продукта) и укажите его в `LAVA_OFFER_ID`.
- Создайте webhook типа «Результат платежа» и укажите URL вида `https://ваш-домен/api/webhook/lava`.
- Для webhook-аутентификации выберите «API key»: LAVA будет присылать ключ в заголовке `X-Api-Key`, который нужно проверять на вашей стороне.

## Переменные окружения

Скопируйте `.env.example` в `.env` и заполните:

- `PRODUCT_NAME`, `PRODUCT_PRICE`, `PRODUCT_CURRENCY`
- `ACCESS_URL` (ссылка-приглашение/входа в канал)
- `LAVA_API_KEY`, `LAVA_OFFER_ID`
- `LAVA_WEBHOOK_API_KEY` (ключ, который будет присылаться в `X-Api-Key` на webhook)
- SMTP-настройки: `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM`

## Запуск локально

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

Откройте: http://localhost:8000/

## Демо-режим (если Lava ещё не подключена)

Если аккаунт Lava ещё не зарегистрирован, можно включить демо-режим, чтобы показать работоспособность лендинга и пользовательского сценария без реального списания денег.

- Установите в `.env`:
  - `PAYMENT_MODE=demo`
- Нажмите «Оплатить» на главной странице — откроется демо-страница `/demo-pay.html`.
- На демо-странице нажмите «Подтвердить оплату (демо)» — заказ будет помечен как оплаченный.

Чтобы включить реальную оплату через Lava:
- Установите `PAYMENT_MODE=lava` (или удалите переменную)
- Заполните `LAVA_API_KEY` и `LAVA_OFFER_ID`

## Как работает

- Страница загружает `/api/checkout/new`, получает номер заказа и отображает товар/цену.
- По кнопке «Перейти к оплате» вызывается `/api/checkout/create`, сервер создаёт контракт через `POST /api/v3/invoice` на `https://gate.lava.top` и возвращает `paymentUrl`.
- Браузер редиректится на `paymentUrl`.
- После оплаты LAVA отправляет webhook `payment.success` со статусом `completed` на `/api/webhook/lava`.
- Сервер находит заказ по `contractId`, помечает как оплачен и отправляет письмо с `ACCESS_URL`.
